# «Поля»: руководство для новичка

Этот проект — автономный редактор рукописных конспектов. Он сделан на React и запускается в оболочке Electron как обычная Windows-программа. Для работы готового `.exe` локальный сервер не нужен.

## Самое важное

- Исходный код интерфейса: `app/page.tsx`.
- Все цвета, размеры и оформление: `app/globals.css`.
- Раскладка текста по страницам: `lib/layout.ts`.
- Перевод миллиметров в пиксели и размеры листов: `lib/units.ts`.
- Работа Windows-окна и печати: `electron-main.cjs`.
- Безопасный мост между интерфейсом и Windows: `electron-preload.cjs`.
- Картинки, иконки и шрифты: `public/`.

Перед изменениями скопируйте всю папку проекта в резервную папку. Не редактируйте готовый `.exe`: он собирается заново из исходников.

## Что установить

1. Установите Node.js версии 22 или новее.
2. Откройте PowerShell в папке проекта.
3. Один раз выполните `npm install`.

## Как посмотреть изменения

Самый простой способ запустить desktop-версию:

```powershell
npm run desktop
```

Окно откроется после завершения сборки. Чтобы только проверить код без запуска окна:

```powershell
npm test
npm run lint
npm run desktop:build
```

## Как собрать EXE

```powershell
npm run exe
```

Готовый переносимый файл появится в папке `release`. Это один `.exe`, установщик не нужен.

## Где менять интерфейс

Откройте `app/page.tsx`. Большая часть кнопок подписана русским текстом, поэтому нужное место удобно искать через `Ctrl+F` по надписи кнопки.

Примеры:

- найдите `workspace-toolbar`, чтобы изменить верхнюю панель инструментов;
- найдите `left-panel`, чтобы изменить левое окно;
- найдите `right-inspector`, чтобы изменить правое окно свойств;
- найдите `settingsOpen`, чтобы изменить настройки;
- найдите `printDialogOpen`, чтобы изменить окно печати;

Не удаляйте обработчики вида `onClick`, `onPointerDown`, `onChange`: именно они делают элементы рабочими.

## Где менять цвета и размеры

Откройте `app/globals.css`.

Цвета тем находятся в правилах `.ui-classic`, `.ui-dark`, `.ui-kawaii` и других. Основные переменные:

- `--app-bg` — общий фон приложения;
- `--chrome` — верхние панели;
- `--panel` — боковые окна;
- `--panel-soft` — карточки внутри окон;
- `--field` — поля ввода;
- `--line` — рамки;
- `--ink` — основной текст;
- `--muted` — второстепенный текст;
- `--accent` и `--accent-2` — кнопки и подсветка.

Меняйте переменные внутри одной темы — тогда вся палитра останется цельной.

## Как добавить тему

1. Добавьте название темы в тип `Settings["uiTheme"]` в `app/page.tsx`.
2. Добавьте карточку темы в массив тем в окне настроек.
3. В `app/globals.css` добавьте правило `.app-shell.platform-desktop.ui-НАЗВАНИЕ` со всеми цветовыми переменными.
4. Проверьте светлый и тёмный текст, рамки, выпадающие меню, окно печати и переключатели.

Карточки всех тем должны иметь одинаковую структуру и размеры. Цвета задавайте переменными темы, а не отдельными случайными значениями внутри компонентов.

## Как устроено рисование

Штрих — это объект `Stroke`: номер страницы, инструмент, цвет, толщина, прозрачность и массив точек. Координаты хранятся в миллиметрах, поэтому рисунок совпадает в предпросмотре и при печати.

- `oldDrawStart` начинает штрих;
- `oldDrawMove` добавляет точки;
- `oldDrawEnd` сохраняет штрих;
- `eraseStrokeAt` разрезает штрих в месте прохождения ластика;
- `pathData` сглаживает точки для SVG.

В режиме вертикальной ленты у каждого листа отдельный SVG-слой и собственный номер страницы.

## Сохранение документов

Проект автоматически сохраняется в хранилище приложения. Комбинация `Ctrl+S` сохраняет немедленно и показывает уведомление. Пункт «Файл → Экспорт» создаёт отдельный файл, который можно открыть позже.

Перед изменением формата сохранения найдите `persistProject` и `openProject`. Добавляя новое поле в `Settings`, обязательно задайте значение в `defaults`, иначе старые документы могут открыться с пустым значением.

## Печать

Печатная версия формируется отдельно от экранного масштаба. Не используйте экранные пиксели для полей печати — размеры должны оставаться в миллиметрах. После любых изменений печати проверьте:

1. A4 и A5;
2. вертикальную и горизонтальную ориентацию;
3. левый и правый переплёт;
4. фон и прозрачность;
5. несколько страниц;
6. выбранный принтер и количество копий.

## Горячие клавиши

- `Ctrl+S` — сохранить;
- `Ctrl+Z` — отменить;
- `Ctrl+Y` или `Ctrl+Shift+Z` — повторить;
- `Ctrl+A` — выбрать строки текущего листа;
- `Ctrl++` и `Ctrl+-` — масштаб;
- удерживать `Пробел` и двигать мышь — перемещаться по рабочему столу;
- двойной клик по строке — редактировать её.

## Если что-то сломалось

1. Запустите `npm test`.
2. Запустите `npm run lint`.
3. Запустите `npm run desktop:build`.
4. Если сборка прошла, откройте приложение и повторите действие на новом пустом документе.
5. Если проблема только в старом документе, экспортируйте его перед сбросом.
6. Проверьте, не осталась ли запущена старая версия `.exe`.

Частые причины:

- элемент виден, но не нажимается — другой слой расположен выше него (`z-index` или `pointer-events`);
- рисунок появляется не на том листе — неверно передан номер страницы;
- печать отличается от экрана — размер посчитан в пикселях вместо миллиметров;
- настройка не запоминается — поле отсутствует в `Settings`, `defaults` или сохранении;
- окно обрезается — у внутреннего контейнера нет `overflow-y: auto`.

## Безопасный порядок работы

1. Сделайте одну небольшую правку.
2. Запустите тесты и сборку.
3. Проверьте нужную кнопку вручную.
4. Только потом переходите к следующей правке.
5. Не удаляйте старый рабочий `.exe`, пока новый не проверен запуском.
