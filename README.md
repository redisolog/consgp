# Поля — A5 конспекты

Локальный desktop-first редактор рукописных конспектов для бумаги A5.

## Запуск

Дважды щёлкните `Запустить.cmd`. После запуска откройте http://localhost:3000.

Все правки и настройки автоматически сохраняются в браузере. PDF и PNG создаются локально и никуда не отправляются.
